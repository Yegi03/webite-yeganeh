This is your first blog post. You can write in **Markdown** — headings, lists, links, code, and more all work out of the box.

## How to add a new post

1. Create a new `.md` file in `content/blog/`
2. Add frontmatter at the top (title, date, description, tags)
3. Write your content below
4. Push to GitHub — your site redeploys automatically

Happy writing.
