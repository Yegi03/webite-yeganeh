This is your first brain note. Use this space for half-formed ideas, things you want to remember, and thoughts in progress.

## How to add a note

1. Create a new `.md` file in `content/notes/`
2. Add frontmatter (title, date, description, tags)
3. Write below — push to GitHub and it goes live

Messy is fine. That's the point of a memory drawer.
